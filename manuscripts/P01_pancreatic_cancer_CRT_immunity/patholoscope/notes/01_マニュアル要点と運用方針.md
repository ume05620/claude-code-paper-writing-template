# Patholoscope 取扱説明書の要点と、CD8計測の運用方針

**作成**: 2026-10-24
**出典**: `manual/Patholoscope_Manual.pdf`(取扱説明書 Version 1.6、三谷商事、2017年作成、48ページ)。ページ番号はマニュアル下部の通し番号(- n -)。
**注意**: 実際に使うのは ver 1.8.0。マニュアルは1.6なので、画面や項目名が少し違う可能性がある。違いに気づいたらこのメモに追記する。

---

## 1. マニュアルからわかったこと

### セットアップ(p1)
- CD-R内の `Setup.exe` → [Install Patholoscope]。
- 動作条件: Windows 10/8.1/8/7/Vista(32/64bit)、CPU 2GHz以上、メモリ2GB以上、HDD 250GB以上、**ディスプレイ解像度1280×1024以上**、**USB空きポート1つ以上**(ライセンスキー用)。
- **Windows 11はマニュアルに記載なし**(マニュアルが2017年のため)。T.S.さんのPCがWindows 11なら、1.8.0での動作を三谷商事に確認する。
- **インストール台数の制限はマニュアルに記載なし**。使用許諾書(CDの箱など)か三谷商事に確認する。

### 画像(p3)
- 開ける形式: FRN、BMP、**JPEG**、PNG、TIFF。ドラッグ&ドロップでも開ける。

### 計測の設定は「レシピ」としてファイル保存できる(p9)
- [レシピ保存]/[レシピ読込]。**同じレシピを梅宮さんとT.S.さんで使えば、計測条件をそろえられる。** レシピファイルは `settings/` に保管し、変更履歴を残す。
- 保存済みレシピを読み込んで設定を変えた場合、変えた値が赤字で表示される(p19)。

### 計測の流れ(第3章 核カウント、p9–19)
CD8は「核カウント(Ki-67)」のタブを使い、陽性・陰性の色を[任意色指定]で設定するのが妥当(褐色=陽性、青=陰性)。

| 手順 | 内容 | CD8での注意点 |
|---|---|---|
| レシピ設定(p9) | 明視野、抽出方法=[任意色指定]、陽性判定の条件([陽性エリア面積>陰性エリア面積]か[○%以上が陽性エリア]) | 陽性判定の条件は一度決めたら固定 |
| Detail(p10) | シェーディング補正(細胞のない所で撮った基準画像が必要)、明るさ、コントラスト | 補正を使うなら全画像で同じ設定 |
| ホワイトバランス(p11) | 背景をクリックするとそこがグレーになるよう補正 | 画像ごとにクリック位置が違うと結果が変わりうる → 撮影時のWBを固定する方が安定 |
| 細胞分離(p12) | 細胞のサイズと染色濃度のスライダーで、数える候補に○をつける | **リンパ球の大きさに合わせる** |
| 陰性/陽性抽出(p13–14) | [抽出色設定]で、陰性細胞・陽性細胞をスポイトでクリックして色を指定 | CD8陽性(褐色)と陰性(ヘマトキシリンの青)をクリック |
| 計測エリア(p15) | [画像全体]/[マニュアル指定]/[自動] | **[画像全体]にする**(視野全体を数える方法のため)。[自動]は細胞の密な所だけを選ぶので使わない |
| 核サイズ・粒子の削除(p16) | 大きい細胞を1個として数える、**小さい粒子(リンパ球)・長い粒子を削除** | **粒子の削除は使わない(0にする)**。マニュアル上「小さい粒子=リンパ球」を消す機能なので、CD8陽性リンパ球が消えてしまう |
| 実行・ランク表示(p17) | 陽性率=陽性細胞数/全細胞数 | — |
| 判定修正(p18) | 計測後に、細胞をクリックして陽性⇔陰性の変更、削除、追加ができる | これがMethodsの「手で陽性細胞を追加・削除」にあたる |
| Excel転送/CSV出力(p18–19) | [環境設定]-[データ転送]で切替。[自動的に保存する]で指定先に自動保存 | CSVで保存し、`results/` に集める |

### 連続実行(第6章、p39–45)= 自動化の本命
- [連続実行]タブで、**指定したフォルダ内の画像をすべて同じレシピで自動計測**できる。
- サンプル名を入力できる → **症例コードをサンプル名にする**。
- [環境設定]-[連続実行]で結果の保存先を指定。**[確認用画像も保存する]**にすると、元画像と計測後の画像を並べた確認用画像が `Prev` フォルダに保存される(合議のときに見返せる)。
- [環境設定]-[データ転送]で **[連続実行時は画像別シートも出力する]** にすると、視野ごとの結果も出る。
- 計測後、結果をダブルクリックすると編集モードになり、その画像だけ設定を変えて計測し直せる(p43)。**ただし手でのクリック修正(追加・削除)がこの編集モードでできるかは、マニュアルからは読み取れない**ので、実機で確認する。
- 結果は「保存先/サンプル名/計測開始日時/」に `計測結果.xml` と `Prev` フォルダとして保存され、後から[計測結果読込]で開き直せる(p45)。
- 計測エリアを[マニュアル指定]にすると、画像ごとに範囲を指定する必要がある(p41)→ [画像全体]なら完全に自動で回る。
- 監視モード: 全画像の計測後も待機し、フォルダに新しい画像が入ると自動で計測する(p41)。

## 2. 運用方針(案)

1. **レシピを1つ決めて固定する**(梅宮さんがライセンスキーを使って作成)。`settings/CD8_recipe_v1.*` として保存し、決めた値を `notes/02_レシピ設定記録.md` に書き残す。
   - 1人目の計測で使ったレシピファイルが残っていれば、それを基準にするのが最も望ましい(2人の計測条件がそろう)。
2. **T.S.さんの作業**: 1症例の4枚を1フォルダに入れる(`images/<症例コード>/`)→ [連続実行]でそのフォルダを指定、サンプル名=症例コード → 確認用画像と結果を見て、誤認識を手で修正 → CSVを `results/` に保存。
3. **集計**: 各症例のCSV(視野ごとの陽性細胞数・全細胞数)を、私がここで集めて記録シートにまとめる(転記ミスを防ぐ)。T.S.さんにPythonは不要。
4. **独立性**: レシピ(機械の設定)は共有してよいが、1人目の計測値・撮影画像・群の情報はT.S.さんに渡さない。
