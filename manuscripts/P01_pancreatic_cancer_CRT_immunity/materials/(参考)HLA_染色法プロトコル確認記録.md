## 1. 発見した完全なHLA class Iプロトコル(和文, スライド7)

> 4マイクロメートル厚の切片をルーチンの手順で脱パラフィンした。pH6.0のクエン酸緩衝液で121℃、10分間煮沸し抗原賦活化処理を行い、室温で1時間冷却した後、脱イオン水で洗浄し、リン酸緩衝生理食塩水で5分間洗浄した。切片を3%過酸化水素で15分間処理し切片の内因性ペルオキシダーゼ活性をブロックした。HLA-classⅠに対する一次抗体(1:400; clone EMR8-5; Hokudo, Sapporo, Japan)を4℃で16時間インキュベートした。アビジン/ビオチン複合標識抗マウス抗体(VECTASTAIN® ABC-HRP Kit)で室温で30分間インキュベートした。その後、切片を緩衝液に洗浄し、ジアミノベンジジン(DAB)(Agilent Technologies, California, USA.)に浸漬して発色を観察した。

**整理すると**:

| 項目 | 内容 |
|---|---|
| 切片厚 | 4µm |
| 抗原賦活化 | クエン酸緩衝液 pH6.0、121℃、10分間煮沸 → 室温1時間冷却 → 脱イオン水洗浄 → PBS 5分洗浄 |
| 内因性ペルオキシダーゼブロック | 3%過酸化水素、15分 |

| 二次抗体 | VECTASTAIN® ABC-HRP Kit(アビジン/ビオチン複合標識抗マウス抗体); 室温・30分 |

| 対比染色・コントロール | **記載なし(未確認事項として残存、下記5節参照)** |

## 2. マーカー間の抗原賦活化条件の比較

自験プロトコル内で、HLA・CD8・PD-L1の抗原賦活化条件を並べると以下の通り。

| 抗原 | 賦活化液 | pH | 温度 | 時間 |
|---|---|---|---|---|
| HLA class I | クエン酸緩衝液 | 6.0 | 121℃ | 10分 |
| CD8 | Target Retrieval Solution | 9.0 | 100℃ | 20分 |
| PD-L1(この草案スライド9) | Target Retrieval Solution | 9.0 | 121℃ | 20分 |

**【重要な留意点】** 当初、この一覧を見て「HLAの賦活化時間(10分)がPD-L1の実プロトコル(`study_protocols/`で確立された120℃・10分)とたまたま一致しているだけで、緩衝液・pHは別物であり、かつこの草案のPD-L1記載(121℃・20分)は実プロトコル(120℃・10分)と矛盾している」という点を「不整合」として指摘したが、**研究者本人の確認により、これは問題ではないことが判明した**。各抗体は実際の組織切片を用いた条件だしによって個別に最適化されており、マーカー間で賦活化条件が異なることも、同一マーカーについて時期によって条件が変遷すること(検討段階の記録と最終採用条件が異なること)も、通常の実験プロセスとして当然である。**したがって上表の差異はMethods執筆上「説明を要する矛盾」としては扱わない。**

## 3. Takehara 2023(引用元)との一次抗体希釈倍率の差異

英文Methods(スライド10)は「previously described immunohistochemical protocols [14–17]」としてTakehara et al. 2023(PMID 37772585, 自施設の先行研究)を踏襲する体裁になっているが、Takehara論文本文(精読済み)のHLA一次抗体条件は:

> HLA class I-ABC (1:200; clone EMR8-5; Hokudo, Sapporo, Japan)

自験(1:400)とは希釈倍率が異なる。

**【留意点】** これも上記2節と同じ理由により「不整合」ではない。引用元の希釈倍率をそのまま踏襲する義務はなく、自験の組織で条件だしを行った結果として異なる倍率を採用すること自体は正当な実験プロセスである。ただし、Methods執筆時に「Takeharaらの手法に準拠した」と書く場合は、細部(希釈倍率・領域数など)が完全一致ではなく自施設での最適化を経たものである旨を一言添えるとより正確になる。

- clone **EMR8-5** は Hiraoka 2020(PMID 32495519)・Takehara 2023(PMID 37772585)双方で使用されている抗HLA class I重鎖モノクローナル抗体で、汎用されている実在クローンであることを確認済み。
- 販売元 **Hokudo(北海道系列, Sapporo, Japan)** の表記もTakehara論文と一致。

## 5. 残存する未確認事項

発見した完全プロトコル(スライド7)にも、以下の記載がない。PD-L1側の詳細手順書(`study_protocols/`)にはMayer's hematoxylin対比染色・rabbit IgGネガティブコントロールの記載があるため、HLAも同様の手順を踏んでいる可能性が高いが、**論文のMethods執筆前に研究者本人の記憶または追加資料で確定させる必要がある**:

- [ ] HLA染色における対比染色(ヘマトキシリン)の有無・条件
- [ ] HLA染色における陽性コントロール・陰性コントロールの設定
