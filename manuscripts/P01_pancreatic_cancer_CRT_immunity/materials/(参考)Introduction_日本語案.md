**第1段落(項目1・2: 予後と組織の特徴)**
膵癌は、集学的治療の進歩にもかかわらず予後が極めて不良な悪性腫瘍であり、長期生存が得られる患者は依然として限られている[Siegel 2025]。膵癌の組織は、腫瘍細胞の占める割合が小さく、豊富な線維性間質と形成不全の血管系を特徴とする[Halbrook 2023; Stoop 2025]。この間質は抗癌剤の到達を妨げるだけでなく、免疫抑制的な微小環境をつくり、細胞傷害性T細胞の腫瘍内への浸潤を制限することが知られている[Kabacaoglu 2018; Balachandran 2019]。

**第2段落(項目3: 標準治療と術前化学放射線療法)**
切除可能な膵癌に対しては、外科的切除と全身化学療法を組み合わせた治療が標準とされているが、多くの患者は微小転移による再発をきたす[Springfeld 2023; Mannucci 2026]。この限界を克服する戦略の一つとして、術前化学放射線療法が検討されてきた。切除可能および境界切除可能膵癌を対象としたPREOPANC試験では、ゲムシタビン併用の術前化学放射線療法により全生存が改善し、5年全生存率は手術先行群の6.5%に対して20.5%であった[Versteijne 2022]。しかし、生存期間中央値の差は1.4か月にとどまり、術前治療の位置づけについてはなお議論が続いている[Versteijne 2022; Springfeld 2023]。膵癌の治療成績の向上は、依然として満たされていない課題である。

**第3段落(項目4・5: ICIの成功例と、膵癌での不良な成績)**
免疫チェックポイント阻害薬(ICI)は、多くの癌腫で治療を大きく変えてきた。切除不能Ⅲ期非小細胞肺癌を対象としたPACIFIC試験では、化学放射線療法後に抗PD-L1抗体durvalumabを投与することで無増悪生存期間が延長し[Antonia 2017]、5年全生存率はプラセボ群の33.4%に対して42.9%であった[Spigel 2022]。一方、膵癌では、放射線治療を併用しないICIの臨床試験はいずれも不良な成績に終わっている。抗CTLA-4抗体ipilimumab単剤では奏効例がなく[Royal 2010]、durvalumabとtremelimumabの併用でも奏効率は3.1%にとどまり[O'Reilly 2019]、nivolumab単剤およびipilimumabとの併用でも奏効は得られなかった[Callahan 2024]。

**第4段落(項目6: 放射線と抗腫瘍免疫、膵癌での不足)**
したがって、膵癌に対して免疫療法を生かすには、新たな治療戦略が必要である。放射線治療は、腫瘍細胞を直接傷害するだけでなく、抗腫瘍免疫を誘導することが示されてきた。われわれはこれまでに、マウスモデルで照射の治療効果にCD8陽性T細胞が関与すること[Yoshimoto 2014]、食道扁平上皮癌で化学放射線療法後に腫瘍抗原特異的T細胞応答が誘導されること[Suzuki 2012]、および直腸癌と食道扁平上皮癌で術前治療により腫瘍細胞のHLA class I発現が増強することを報告してきた[Sato 2014; Takehara 2023]。腫瘍細胞表面のHLA class Iは、細胞傷害性T細胞が腫瘍抗原を認識するために不可欠な分子であり、その発現の低下や消失は抗腫瘍免疫からの逃避機構の一つである[Hiraoka 2020]。また、腫瘍細胞が発現するPD-L1は、T細胞上のPD-1に結合してその機能を抑制する分子であり、抗PD-1/PD-L1抗体の標的である[Kabacaoglu 2018]。膵癌においても、術前化学放射線療法後にCD8陽性T細胞の浸潤が増加したとする報告がある[Homma 2014; Gartrell 2022]。しかし、これらの研究は症例数が少なく、化学療法の内容や照射線量も研究ごとに異なる。さらに、HLA class Iについては結果が一致しておらず[Homma 2014; Michelakos 2021]、CD8陽性T細胞、HLA class I、PD-L1を同時に評価した報告は乏しい。放射線治療が膵癌の免疫微小環境を賦活するかどうかを明らかにすることは、膵癌に対する免疫療法の可能性を検討するうえで欠かせない。

**第5段落(項目7: 本研究の目的)**
本研究では、ゲムシタビン併用の術前化学放射線療法後に切除された膵癌組織と、術前治療を行わずに切除された膵癌組織を用いて、腫瘍浸潤CD8陽性T細胞、HLA class I、PD-L1の発現を免疫組織化学的に評価し、術前化学放射線療法が膵癌の腫瘍免疫を賦活するかどうかを検討した。
