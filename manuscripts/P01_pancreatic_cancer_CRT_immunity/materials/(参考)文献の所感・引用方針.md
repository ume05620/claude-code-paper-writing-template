## Takehara(PMID 37772585)

**出典**: Takehara Y, et al. Immunological Responses Associated With Neoadjuvant Therapy in the Tumor Microenvironment of Esophageal Squamous Cell Carcinoma. Anticancer Research. 2023;43(10):4691-4700.

**要約(`references/summaries/Takehara_ESCCimmuneresponse_37772585.md`より移動)**:
- 単施設(福島県立医科大学)・後ろ向き観察研究。食道扁平上皮癌(ESCC)の術前治療前後のペア検体(生検・手術検体)で腫瘍微小環境の免疫学的変化を評価。
- 対象: 根治手術49例(NAC群30例、NACRT群11例、術前治療なし群8例)。化学療法はフッ化ピリミジン系+プラチナ系、放射線治療は40または42Gy(20〜21分割)。
- 評価項目: CD8、HLA class I-ABC、PD-L1、PD-L2、CEACAM-1、LSECtin、p-STAT1の免疫組織化学的発現。統計は治療前後のペア比較。
- 主要結果: 腫瘍浸潤CD8+T細胞頻度はNAC後に有意増加(p<0.05)。HLA class I-ABC発現はNAC後・NACRT後いずれも有意増加(p<0.05)。PD-L1・PD-L2・CEACAM-1はESCC細胞に発現あり。PD-L1発現とp-STAT1発現に有意な正の相関(p<0.05)。
- 結論: NAC・NACRTはESCC患者に好意的・非好意的双方の免疫学的変化を誘導し、進行ESCCへの免疫チェックポイント阻害薬併用療法の基盤となりうる。

**引用の方向性**:
- 自験施設(福島県立医科大学)の関連研究であり、同一の評価軸(CD8・HLA class I・PD-L1)で術前治療による腫瘍微小環境変化を検討した先行研究として、Discussionで直接比較可能。膵癌と食道扁平上皮癌という異なる癌腫間で、NACRTによるCD8浸潤・HLA class I発現増強という共通した知見が得られている点を論拠として引用する。
- NACRTだけでなくNAC単独でもHLA class I増強が認められている点は、放射線治療の寄与を論じる際の比較対象として有用(化学療法単独の寄与分と放射線治療の上乗せ効果を区別する材料になる)。

**引用時の注意点**:
- NACRT群はn=11と小規模であり、統計的検出力は限定的。
- ESCCはPDACとは発生母地・組織型が大きく異なり、免疫微小環境の性質も異なる可能性があるため、外挿には注意が必要。
- 自施設の関連研究であるため、引用時に利益相反や研究グループの関連性について適切に記述する。
