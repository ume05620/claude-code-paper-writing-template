## 項目1: 膵癌は予後が非常に悪い

| 事実 | 出典 |
|---|---|
| 膵癌は米国のがん死亡原因の第3位 | Siegel 2025, p17 |
| 5年相対生存率は1990年代半ばの4%から2014–2020年の13%に上昇したが、これは偶発的に見つかる高分化神経内分泌腫瘍の増加による見かけ上の部分がある。**膵腺癌に限ると5年生存率は8%**、生存期間中央値は1年未満 | Siegel 2025, p19 |
| 全病期の生存期間中央値は4か月。診断時に半数強が遠隔転移あり。2030年までに米国のがん死亡原因の第2位になると予測 | Stoop 2025 (Lancet), p1 |

**メモ**: 梅宮さんの方針(罹患・死亡の数値は出さない、予後不良だけ述べる)なら、「5年生存率がなお低い」程度の記述にSiegel 2025を付ければ足りる。数字を1つだけ添えるなら「膵腺癌の5年生存率 8%」(Siegel p19)が最も正確。

## 項目2: 間質が多く血管に乏しい、免疫抑制的な腫瘍

| 事実 | 出典 |
|---|---|
| 膵癌の微小環境は、多数の線維芽細胞、密な細胞外基質、**形成不全の血管系**、主に抑制性の免疫細胞から成る。**腫瘍細胞は腫瘍全体の細胞の少数派**であることが多い | Halbrook 2023 (Cell), p11 |
| 物理的な障壁が血液由来の栄養と酸素の到達を制限し、局所的な低酸素を生む | Halbrook 2023, p15 |
| 膵癌は線維形成性(desmoplastic)間質を特徴とし、間質圧の上昇が抗癌剤の到達を妨げる | Stoop 2025, p2 |
| 密な線維形成性間質が、放射線・化学療法への反応の低さの一因 | Kabacaoglu 2018, p2 |
| 多くの癌腫で細胞傷害性T細胞の浸潤がみられるが、**PDACは例外的**で、前癌病変の段階から微小環境が細胞傷害性T細胞の浸潤を制限する。浸潤しても、CAF・骨髄系細胞・一部のT細胞が機能を抑える | Kabacaoglu 2018, p8 |
| PDACは密な線維形成(活性化した膵星細胞がコラーゲン等を産生)を特徴とし、この間質成分は免疫抑制的と考えられている。膵星細胞はCXCL12依存的にCD8+T細胞を隔離する | Balachandran 2019, p4 |
| 腫瘍細胞のHLA class I発現の低下・消失は抗腫瘍免疫からの逃避機構。PDAC 243例で**HLA class I低発現は33%**、低発現の方が全生存が長かった(高発現がむしろ予後不良) | Hiraoka 2020, p1 |

**メモ**: 「充実成分(腫瘍細胞)が少ない」→ Halbrook p11、「血管増生に乏しい」→ Halbrook p11(poorly formed vascular system)、「間質が多い」→ Stoop p2 / Balachandran p4、「T細胞が入りにくい」→ Kabacaoglu p8。Hiraokaは項目2より、HLA class Iを調べる意義(項目6〜7)かDiscussionで使う方が自然。

## 項目3: 手術と化学療法が標準、術前化学放射線療法は一定の効果があるがunmet

| 事実 | 出典 |
|---|---|
| 局所PDACは、原発巣の切除と全身化学療法の組み合わせが最良で、どちらか単独よりも全生存が大幅に長い。それでも大半は微小転移により再発する | Springfeld 2023, p1 (抄録) |
| 切除可能PDACでは**術後の多剤併用化学療法が標準治療**。術前治療の役割は**なお議論が続いている** | Springfeld 2023, p1 (抄録), p16 |
| 切除可能で術後化学療法(通常6か月)を受けられた患者の5年生存率は30–50% | Springfeld 2023, Key points (p1) |
| 根治の可能性があるのは手術のみだが、診断時に切除可能なのは15–20% | Mannucci 2026, p1 |
| 術後補助化学療法は標準だが、生存への効果は初期の試験では結果が分かれていた。ESPAC-1とCONKO-001が確立 | Mannucci 2026, p10 |
| **PREOPANC(第Ⅲ相、オランダ16施設、246例)**: 術前化学放射線療法(ゲムシタビン3コース+36 Gy/15回)→手術→術後ゲムシタビン4コース vs. 手術先行→術後ゲムシタビン6コース。追跡中央値59か月で全生存は術前CRT群が良好(HR 0.73, 95% CI 0.56–0.96, P=.025)。生存期間中央値の差は1.4か月(15.7 vs 14.3か月)だが、**5年全生存率は20.5% vs 6.5%** | Versteijne 2022 (PREOPANC長期成績), p1 |
| 同試験の初回報告では全生存の有意差は示されなかった。術前化学放射線療法の利益は議論が続いている | Versteijne 2022, p1 |

**メモ**: 「一定の効果はある(PREOPANCで5年生存20.5% vs 6.5%)」が「生存期間中央値の差は1.4か月しかなく、長期生存はなお一部」→ unmet needs、という流れが組める。

## 項目4: ICIの成功例 — PACIFIC試験

| 事実 | 出典 |
|---|---|
| 切除不能Ⅲ期非小細胞肺癌で、白金併用の化学放射線療法後に進行のない患者を対象に、durvalumab(抗PD-L1抗体)の地固め療法をプラセボと比較(2:1、713例無作為化) | Antonia 2017 (NEJM), p1 |
| 無増悪生存期間中央値 **16.8か月 vs 5.6か月**(HR 0.52, 95% CI 0.42–0.65, P<0.001) | Antonia 2017, p1 |
| 24か月全生存率 66.3% vs 55.6%、全生存のHR 0.68(99.73% CI 0.47–0.997, P=0.0025) | Antonia 2018 (NEJM), p1 |
| 約5年の追跡で、**5年全生存率 42.9% vs 33.4%**、5年無増悪生存率 33.1% vs 19.0%。全生存期間中央値 47.5 vs 29.1か月(HR 0.72) | Spigel 2022 (JCO), p1 |

**メモ**: 本研究の流れでは「化学放射線療法のあとにICIを加えると生存が延びた」という点が要。数値は5年成績(Spigel)を中心にし、初回報告(Antonia 2017)を併記するのが簡潔。

## 項目5: PDACでは放射線を併用しないICIの成績は不良

| 事実 | 出典 |
|---|---|
| **Ipilimumab単剤(抗CTLA-4)第Ⅱ相**、局所進行・転移性膵癌27例: RECISTでの奏効例なし(1例で遅発性の縮小) | Royal 2010, p1 |
| **Durvalumab±tremelimumab 第Ⅱ相**、転移性PDAC 65例(一次治療後): 奏効率 併用3.1%、単剤0%。拡大の基準(奏効率10%)に届かず | O'Reilly 2019 (JAMA Oncol), p1 |
| **CheckMate 032**、既治療の進行・転移性膵癌: nivolumab単剤(18例)、nivolumab+ipilimumab(21例)では奏効なし。cobimetinibを加えた3剤(30例)で奏効率6.7%(研究者判定)/10%(中央判定)。全生存期間中央値 5.1、4.0、6.2か月 | Callahan 2024 (CheckMate 032), p1 |
| 例外: **MSI-H/dMMR**の非大腸癌(KEYNOTE-158)ではpembrolizumabの奏効率34.3%。ただし**膵癌22例に限ると奏効率18.2%**、無増悪生存期間中央値2.1か月 | Marabelle 2020 (JCO), p1, p6 |

**メモ**: CheckMate 032の著者は第一著者 Callahan M(J Immunother Cancer 2024)。引用候補リストでは「CheckMate 032」としていたので、書誌は Callahan M, et al. で登録する。

**注意(項目4→5の論理)**: Gartrell 2022 の考察(p7)に「PDACでは抗PD-1/PD-L1・抗CTLA-4は、単独でも併用でも、**放射線治療や化学療法と組み合わせても**ほとんど効果がない」とある。つまり「放射線を併用すればPDACでもICIが効く」とは言えない。項目5は「放射線非併用のICIが不良」と限定して書き、項目6では「放射線がPDACの免疫環境を変えるかどうか自体がまだ十分わかっていない → だから組織で調べる」とつなぐのが安全。「PACIFICのように放射線＋ICIならPDACでも効くはず」と読める書き方は避ける。

## 項目6: 放射線治療は他の癌腫で腫瘍免疫を賦活する/膵癌ではどうか

### 他の癌腫(自施設の研究)

| 事実 | 出典 |
|---|---|
| マウスモデルで、放射線照射による腫瘍特異的免疫が照射の治療効果に必須。抗CD8抗体でCD8+細胞を除くと効果が低下し(腫瘍増殖遅延 15.4→8.7日)、抗CTLA-4抗体の併用で効果が増強 | Yoshimoto 2014 (PLoS One), p1 |
| 食道扁平上皮癌で、化学放射線療法後に腫瘍抗原特異的T細胞応答を16例中6例(38%)で確認。腫瘍内HMGB1が化学放射線療法群でのみ上昇し、生存と相関 | Suzuki 2012 (Cancer Res), p1 |
| 局所進行直腸癌78例で、術前温熱化学放射線療法後に**腫瘍細胞のHLA class I発現が有意に増加**(p<0.01) | Sato 2014 (PLoS One), p1 |
| 食道扁平上皮癌49例で、術前化学療法でCD8+TILが増加、術前化学療法・術前化学放射線療法で**HLA class Iが増加**(p<0.05) | Takehara 2023 (Anticancer Res), p1 |

### 膵癌で術前治療後の免疫を調べた先行研究(重要)

| 研究 | 対象・治療 | 結果 | 出典 |
|---|---|---|---|
| Homma 2014 (Ann Surg Oncol) | 52例(NACRT 22、手術単独 30)。GEM+S-1を2コース→**30 Gy**+S-1 | **CD4+・CD8+細胞はNACRT群で有意に多い**(p=0.04, 0.003)。**MHC class Iは群間差なし**。NACRT群ではCD8+が多いと全生存が長い | p1, p2, p3 |
| Gartrell 2022 (Oncoimmunology) | 44例(CRT 18、未治療 26)。IMRT **50.4 Gy/28回+capecitabine** または SBRT 33 Gy/5回 | CRT群でCD3+T細胞(p=.0006)、**CD8+(p=.0079)**、CD4+、Tregが増加。抗原提示関連遺伝子の発現上昇。ただしT細胞の空間的な集まり方は乏しい | p1, p2 |
| Michelakos 2021 (JNCI) | 248例。FOLFIRINOX±化学放射線療法(光子 50.4 Gy/陽子 25 Gy)、または術前治療なし | FOLFIRINOX群でHLA-A欠損が少なく(p=.006)、CD8+浸潤が最も密。HLA class IIは光子群で最も低い | p1 |

**メモ(位置づけに直結)**:
- 膵癌のNACRT後にCD8+が増えるという報告はすでにある(Homma、Gartrell)。**「膵癌では未知」とは書けない**。
- 先行研究は、症例数が少なく、レジメンもばらばら(GEM+S-1+30 Gy、capecitabine+50.4 Gy、FOLFIRINOX中心)。**ゲムシタビン併用・54 Gyの通常分割NACRT**で、**CD8・HLA class I・PD-L1を同時に**評価した報告は見当たらない。
- HLA class IはHomma(差なし)とMichelakos(FOLFIRINOXで欠損が少ない)の2報のみで、結果も一致していない。PD-L1を組織で評価した報告は、この3報には含まれない(3報の本文をPD-L1で検索して確認。Gartrellは考察と文献欄で触れるのみ)。
- **本研究ではCD8に有意差がなかったので、HommaやGartrellとは結果が異なる。** Introductionでは「報告は少なく一貫していない」とまとめ、違いの考察(線量・レジメン・評価法・症例数)はDiscussionで行う。
