## 1. 変数の定義

```python
# HLA１〜９
df = df.rename(columns={'HLA１': 'HLA1', 'HLA２': 'HLA2', ..., 'HLA９': 'HLA9'})
# 欠損地を考慮した平均値の算出
df['HLAmean'] = df[['HLA1', ..., 'HLA9']].mean(axis=1)

df['HLAclass'] = df['HLAmean'].apply(
    lambda x: 0 if x < 1
    else 1 if x < 10
    else 2 if x < 50
    else 3 if x < 80
    else 4 if x < 100
    else np.nan)
```

- 元データには症例ごとに9個の視野の陽性率(%)の列(`HLA1`〜`HLA9`)があり、**`HLAmean`はその9視野の単純平均(%)** — これが過去資料の「陽性率平均(SD)」の出所。
- **`HLAclass`は`HLAmean`をTakehara 2023と同一のカットオフ(0/1/10/50/80%)で0〜4のスコアに変換したもの** — これが過去資料の「スコア中央値」の出所。
- つまり「スコア」と「陽性率」は対立する2つの変数ではなく、**同じ生データ(9視野平均%)を、生の%のまま使うか、スコアに丸めてから使うかの違い**でしかない。

## 4. ASTRO抄録の数値(2.24–2.70 / 1.78–2.64)の正体 — 群のラベルが入れ替わっていた

ASTRO抄録の数値は中央値+ブートストラップCIではなく、**HLAclassスコアを連続値とみなした平均値±t分布95%CI**という、別の統計手法で計算されたものであることが判明した(生データから再計算して確認)。

**生データから再計算した結果**:

| Induction | n | スコア平均 | SD | 平均のt分布95%CI |
|---|---|---|---|---|
| 0(手術単独群) | 62 | 2.468 | 0.900 | **(2.24, 2.70)** |
| 1(NACRT群) | 24 | 2.208 | 1.021 | **(1.78, 2.64)** |

<p><b>これはASTRO抄録の記載と数値そのものは一致するが、群のラベルが逆になっている。</b>ASTRO抄録は「NACRT群 +2.0(95%CI 2.24–2.70)/ 手術単独群 2.0(95%CI 1.78–2.64)」としていたが、正しくは「手術単独群が(2.24–2.70)、NACRT群が(1.78–2.64)」。</p>

**結論**: ASTRO抄録は計算方法自体は妥当(平均±t分布CI)だが、NACRT群と手術単独群の値を取り違えて記載していた可能性が高い。既に採用方針が「スコア中央値方式」(バイオセラピィ抄録型)に決定しているため、この平均値±CI版の数値は最終原稿では使用しないが、抄録の記載ミスとして認識しておく必要がある。

## 5. 二値化(0–2 vs 3–4)比較 — Takeharaと同じ区切りで実施済み

`HLAclass`のカットオフ80%未満/以上に対応する`HLAclass_cutoff50`(HLAmean 50%を境に二値化 = スコア0–2 vs 3–4と同値)がすでに計算されていた。

```python
dfA = pd.crosstab(df["Induction"], df["HLAclass_cutoff50"])
oddsratio, p_value = stats.fisher_exact(dfA)
```

**実行結果(出力そのまま)**:
```
クロス集計表:

Induction
0.0                 32   30
1.0                 14   10

Fisherの正確検定のp値: 0.635191954329263
```

| | 低発現(スコア0–2) | 高発現(スコア3–4) |
|---|---|---|
| 手術単独群(n=62) | 32 | 30 |
| NACRT群(n=24) | 14 | 10 |

**Fisher正確検定 p=0.635(有意差なし)** — Takeharaと同じ0–2/3–4の二値化区分で、自験データを使った比較がすでに実行可能な形で存在していた。
