<h2><span style="color:#1a3c6e; font-size:1.3em; font-weight:bold;">3. 数値・記述の整合性チェック結果</span></h2>

<p><span style="color:#555555;">3回の発表資料を数値レベルで突き合わせた結果、以下の点で記載の揺れ・不一致が見つかりました。論文執筆前に、どれが最終的に正しい数値かを確認してください。</span></p>

<h3><span style="color:#c0392b; font-size:1.15em; font-weight:bold;">🔴 最重要: 臨床病期→病理病期の統計的有意差の p 値が資料ごとに異なる</span></h3>

同じ「NACRTによる病期変化」を指しているとみられる比較で、<b>3つの異なるp値</b>が登場しています。

| 資料 | 記載内容 | p値 |
|---|---|---|
| ASTROポスター(表) | Pathologic tumor status(病理T病期、群間比較): T1/T2 11 vs 7、T3 13 vs 55 | <span style="color:#c0392b; font-size:1.05em;"><b>p=0.001</b></span> |
| ASTROポスター(表) | T downstaging(ダウンステージ有無、群間比較): 観察9 vs 3、非観察15 vs 59 | <span style="color:#c0392b; font-size:1.05em;"><b>p=0.0003</b></span> |
| ASTRO抄録(本文) | 「A statistically significant difference was observed <b>between the cohorts</b>」(病理T病期の比較として記載) | <span style="color:#c0392b; font-size:1.05em;"><b>p=0.01</b></span> |
| バイオセラピィ抄録(本文) | 「手術単独群では臨床病期に比べ病理病期にT3症例が多かった」(<b>群内</b>のclinical→pathological比較) | <span style="color:#c0392b; font-size:1.05em;"><b>p=0.01</b></span>(手術単独群)/ p=0.12(NACRT群) |

<p><span style="color:#555555;">ASTRO抄録は「between the cohorts(群間)」の比較としてp=0.01を報告していますが、ポスターの表では同じ群間比較にp=0.001という別の値が使われています。さらにバイオセラピィ抄録では、比較の枠組み自体が「群間」ではなく「各群内でのclinical→pathologicalの変化」という<b>別の統計検定</b>に変わっており、たまたま同じp=0.01という値が(手術単独群の群内比較として)再登場しています。これが偶然の一致なのか、実際には同一の解析を指しているのに記述が揺れているだけなのか、研究者ご本人が元データ・統計ソフトの出力に立ち返って確認する必要があります。</span></p>

<h3><span style="color:#c0392b; font-size:1.15em; font-weight:bold;">🔴 HLA class I 発現の指標が「スコア中央値」と「陽性率平均」で入れ替わっている</span></h3>

| 資料 | 指標の種類 | NACRT群 | 手術単独群 |
|---|---|---|---|
| ASTRO抄録 | スコア中央値(95%CI) | +2.0 (95%CI 2.24–2.70) | 2.0 (95%CI 1.78–2.64) |
| ASTROポスター | スコア中央値 / <b>陽性率平均(SD)</b> | +2 / 35.76%(SD 29.40) | +2 / 46.62%(SD 26.80) |
| バイオセラピィ抄録 | スコア中央値(95%CI) — <b>両群で同一のCI</b> | 2.0 (95%CI 2.0–3.0) | 2.0 (95%CI 2.0–3.0) |
| バイオセラピィスライド | スコア中央値 / 陽性率平均(SD) | +2 / 35.76%(SD 29.40) | +2 / 46.62%(SD 26.80) |

<p><span style="color:#555555;">同じ「HLA class I発現」について、<b>抄録は毎回スコアの中央値+95%信頼区間</b>を、<b>ポスター/スライドは毎回陽性率(%)の平均値+標準偏差</b>を報告しており、指標が体系的にねじれています。加えてバイオセラピィ抄録だけ、NACRT群・手術単独群の95%CIが完全に同一(2.0–3.0)になっており、ASTRO抄録の値(2.24–2.70 / 1.78–2.64)と食い違います。</span></p>
<p><span style="color:#196f3d;">[解決済み 2026-08-15] <b>元の解析ノートブック(<code>膵癌解析v20250211から生存時間に関するセルをカット.ipynb</code>)を直接確認し、数値を確定した。</b>証拠抜粋は<code>materials/(参考)HLA_数値確定_ノートブック証拠抜粋.md</code>に保存済み。</span></p>
<ul>

<h2><span style="color:#1a3c6e; font-size:1.3em; font-weight:bold;">4. 論文執筆に向けて確認・整理すべき事項</span></h2>

<ol>
<li><span style="color:#196f3d;">[ほぼ解決] <b>病理病期比較のp値</b> → 中間報告(2025-02-14ドラフト、患者背景表)でPathologic tumor status(T1/2 vs T3)が<b>p=0.001</b>と明記されており、ASTROポスター表・統計照合結果と一致。ASTRO抄録本文の「p=0.01」・バイオセラピィ抄録の「p=0.01(群内比較)」は別の検定(群内clinical→pathological変化)か誤記と考えられる。論文には群間比較のp=0.001を採用する方向で問題なさそう。</li>
<li><span style="color:#196f3d;">[解決済み 2026-08-15] <b>HLA class Iの報告指標</b></span>: Takehara et al. 2023(PMID 37772585)に合わせスコア(0–4)中央値方式に統一する方針を決定。元データから再計算した結果、<b>NACRT群・手術単独群とも中央値2.0(95%CI 2.0–3.0)</b>で確定(バイオセラピィ抄録の記載が正しかった)。ASTRO抄録の値(2.24–2.70 / 1.78–2.64)は別の統計手法(平均値±t分布CI)によるもので、かつ群のラベルが逆に記載されていたことが判明(<code>materials/(参考)HLA_数値確定_ノートブック証拠抜粋.md</code>参照)。あわせてTakeharaと同じ0–2 vs 3–4の二値化比較(Fisher正確検定 p=0.635)も併記する。</li>
<li><span style="color:#196f3d;">[解決済み] <b>TIL群間比較の変数取り違え問題 — 元ノートブックで原因・正しい数値とも確定</b></span>: 元解析ノートブック(<code>C:\Users\pureb\OneDrive\JupyterNotebook\膵癌\膵癌解析v20250211から生存時間に関するセルをカット.ipynb</code>)を直接確認した結果、以下が判明した。
<ul>
<li><b>変数の定義</b>: <code>CD8mean</code> = 4視野の陽性率(%)の単純平均(=当初計画していた比率法そのもの)。<code>CD8all_mean</code> = 4視野の陽性細胞<b>数</b>の合計÷4(絶対数、比率ではない)。</li>
<li><b>原因確定</b>: <code>CD8all_mean</code>を計算しているセルには、研究者自身による「<code>#★★CD8all_meanは指標として誤用なのでこれは使用しないように★★</code>」という警告コメントが残っていた。<b>3回の学会発表すべてで報告された中央値(63.88/53.75)は、この誤用と分かっていた<code>CD8all_mean</code>由来だった。</b></li>
<li><b>正しい変数(CD8mean、警告コメントなし)の実際の値</b>: NACRT群 中央値<b>8.525</b>(95%CI 6.975–12.65)、手術単独群 中央値<b>7.2625</b>(95%CI 6.375–8.35)。群間比較のMann-Whitney U検定: <b>p=0.1017(≈0.10)</b>(中間報告スライド21の箱ひげ図と対応する値と一致)。</li>
<li><b>結論への影響</b>: 「NACRT有無でTILに有意差なし」という主結論は変わらない。変わるのは学会発表で提示していた具体的な数値のみ(誤った変数から正しい変数への訂正)。方法論(比率法・4視野平均)自体は当初から正しく実装されていた。</li>
<li>証拠抜粋(実際のコード・出力原文)を <code>materials/(参考)CD8_変数問題_ノートブック証拠抜粋.md</code> に保存済み(参考資料化)。教授説明用pptx(<code>materials/(参考)CD8_TIL評価法_教授相談用.pptx</code>、参考資料化)にも反映済み。</li>
</ul>
</li>
<li><span style="color:#c0392b;"><b>[新規・重要] 「比率の平均」と「合計の比率」は数学的に別物 — 元データに3つ目の候補変数(合計の比率)が既存</b></span>: ユーザーからの指摘(1枚ごとの割合を出してから4枚平均するのと、4枚合計の陽性数÷4枚合計の全細胞数とでは値が違うのではないか)を受け、生データ(<code>20250211cTNMを追記した解析ファイル.csv</code>)を直接読み込んで検証した。
<ul>
<li>4視野の全細胞数は症例ごとに変動係数(CV)中央値13.0%(範囲2.3〜63.1%)とばらつきがあり、「比率の平均」(CD8mean)と「合計の比率」(陽性数合計÷全細胞数合計)は症例によって最大20.7ポイント乖離する(86症例、相関r=0.91)。</li>
